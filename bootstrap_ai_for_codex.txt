SECTION E - FAST DEPLOY METHOD (PREFERRED)
============================================================

Goal
- Avoid slow in-cluster source builds.
- Build image locally, push to registry, deploy immutable tag with Helm.

Steps
1) Login to OpenShift internal registry
  - Get user/token via oc and run docker login to image-registry.apps.gold.devops.gov.bc.ca.

2) Build app image locally
  - Dockerfile: devops/docker/app/Dockerfile
  - Tag pattern: image-registry.apps.gold.devops.gov.bc.ca/ce8baa-dev/energy-app:<immutable-tag>

3) Push image
  - Push same immutable tag to internal registry.

4) Helm deploy with explicit app image override
  - Keep command in helm/main with values.yaml + values-ce8baa-dev.yaml.
  - Set app.image.repository and app.image.tag to the pushed image.

5) Verify rollout
  - oc -n ce8baa-dev get pods
  - oc -n ce8baa-dev get deploy hesp-app -o yaml | grep image:
  - Confirm UI/routing updates are present.

Notes
- This is the default path when user asks for rapid deploy of latest code.
- Use in-cluster BuildConfig only if local build/push is blocked.
